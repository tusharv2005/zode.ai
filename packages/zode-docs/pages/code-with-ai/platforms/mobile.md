# Mobile Apps

Use Zode Code from your phone to keep coding sessions moving while you are away from your desk. The mobile app connects to Cloud Agents, ZodeClaw, and remote sessions from your local CLI or editor extensions.

{% callout type="info" title="Android app available now" %}
Install Zode Code for Android from [Google Play](https://play.google.com/store/apps/details?id=com.zodecode.zodeapp).
{% /callout %}

## What you can do

The mobile app lets you:

- View and manage Zode Code sessions, including remote CLI and extension sessions running on your local machine.
- Chat with ZodeClaw from your phone.
- Spawn Cloud Agents and code directly from the app.
- Monitor and view all non-remote sessions in one place.
- Create, onboard, and manage ZodeClaw instances.
